# Sistema endocrino paso a paso

Guía de estudio interactiva del sistema endocrino: glándulas y hormonas, eje hipotálamo-hipofisario, retroalimentación y homeostasis, hormonas y conducta, y hormonas y desarrollo. Incluye casos resueltos paso a paso, práctica con autoevaluación de confianza, juego de unir y simulacro en tres niveles.

Sitio estático: `index.html` + `assets/`. Se publica con GitHub Pages desde la rama `main`.
